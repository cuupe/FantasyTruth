# FantasyTruth · 阿比斯探窟

适用于 Minecraft 1.20.1 和 NeoForge 47.1.106。替换旧版模组 JAR 后，新建世界并选择 **FantasyTruth：阿比斯探窟 · 奥斯**。奥斯岛固定围绕 X=8、Z=8 的深渊生成，出生广场在洞口北侧。岛屿约 3,050 × 2,950 格，外海使用深海群系，海平面为 Y=78。最高山脊约为 Y=780。

奥斯位于朝向洞口的内坡。海侧高崖与山脊环抱城市，沟壑把连绵的屋顶分成数个街区。房屋沿弯曲短街、岔巷和坡地分布，逐栋取地基高度。石阶与挡土墙只在街路和宅地附近出现。西侧孤儿院立在林坡上，大码头伸入洞口。东侧公会靠岩脊，南侧岸壁街贴着洞壁向下展开，南港位于单独的入海口。

岛形、林地、地标和街屋轮廓按区块生成。外岛坡面覆盖草土、根系和苔藓，海岸以沙砾过渡。深渊洞壁从奥斯几乎垂直向下，分布着断崖、峡沟和数道跌水。从奥斯向下可看到与第一层共用地形轮廓的上部岩棚。方块贴图来自随项目提供的 `abis/blocks/textures`。

洞口中心为 X=8、Z=8。在洞口范围内下潜到 **Y=-8** 会进入独立的第一层维度，X、Y、Z、速度和朝向在接缝处连续。第一层复制接缝上方的洞口轮廓，主世界也生成 Y=-480 以上的第一层岩棚、植被和探窟建筑，两条梯道和落脚平台在切层前后使用相同的坐标。升到 **Y=+8** 可返回主世界，缓冲区内保留当前维度。接近层间通道时，服务端提前请求目标区块。正常穿过通道时保留横向坐标、朝向、速度和状态效果，客户端在收到近处区块后把上一帧淡接到新景。这个过程也用于第一层往返第二层和更深处的层间通道，各层使用同一昼夜时钟。第一层出口下方的新区块使用第二层的同一批岩棚和树冠。

第一层 **边缘之渊** 覆盖深度 0–1,350 格。沿天然岩棚可探索附壁草甸、白花坡、石化巨木林、泉池、苔藓蕨坡和白垩碎石坡。岩壁里有带断柱、石拱和残灯的遗迹，短碎石路只在少数位置出现。林地混生原版橡树、桦树、杜鹃树与少量分枝石化巨木。上层可进入吊唁之塔，深约 600 格有石之方舟。沿途可偏离主路搜寻岩穴和营地中的食物、火把、攀登物资和少量遗物碎片。

新建的阿比斯探窟世界使用素材库的深渊岩生成奥斯岛的天然岩壁。第一层在 Y=-1240 附近接入林冠盆地。盆地中央的林海被深谷切开，错层断崖和挂满根系的岩舌伸向谷心。沿岩棚下探，越过 Y=-1350 进入第二层；切层前后共用谷口轮廓。新版入口随新建存档生成。

在奥斯或第一层输入 `/abyss entrances` 查看三条入口的坐标。奈落之门后的石道和梯道通向上层草地，岸壁街的木栈道和攀爬梯通往泉畔岩台，大码头与石舟站可右键站台钟往返。入口建筑随新区块生成。`/abyss route` 可查看第一层步道和地标，`/abyss` 显示当前深度。吊唁之塔、石之方舟、石化巨木和附壁草地取材自原作，步道、营地和可进入的岩穴按游戏地图布局。 [动画第 4 话](https://miabyss.com/story04.html) · [漫画第 1 卷](https://miabyss.com/comics.html)

新建阿比斯探窟世界时，第一层会生成附壁岩台、错层悬台、沟谷和崩积坡。靠岩壁一带分布斜沟、灌木丛和石化巨木，沿途有落石、废弃补给点和残垣。岩壁中按世界种子分布支洞、天然洞厅和有木支架的旧矿洞，深处有少量遗物矿或补给。草甸有成片的深渊草簇，湿地长芦苇，背阴林地分布发光苔藓和菌菇，岩棚下垂着根系。旧存档沿用创建时的第一层布局。

从 **0.10.1** 开始，第一层新生成的岩壁、岩棚和部分岩穴有可用石镐采掘的遗物矿。常见掉落是标记了来源层的遗物碎片，偶尔可挖到无花纹遗物，也可能挖出燧石或粗铜。遗址藏箱保留骨头、铜料、陶片等原版掉落，并有额外机会出低价值遗物。探窟装备包含铁级探窟镐和可右键读数的深度计。

**0.11.0-alpha.6** 收录了 `abis` 的 107 种方块、37 个有独立模型的物品与变体，以及掉落清单中的材料。创造物品栏分为「阿比斯 · 方块」「阿比斯 · 遗物」「阿比斯 · 探窟装备」「阿比斯 · 材料与补给」。三种流体通过桶取用。部分遗物与装置目前可陈列，专属能力和世界生成另行接入。素材导入脚本为 `python tools/import-abyss-catalog.py ../abis`。

从 **0.11.0-alpha.8** 开始，第一层岩棚有成群活动的锤喙，天然洞厅有丝牙，湿地水潭有恶魔鱼，偶尔可见迁徙的红口裂蛇。锤喙遇袭会呼援，丝牙在洞内伏击，红口裂蛇鸣叫蓄势后会向目标可能到达的位置俯冲。满足栖息地条件的旧区块也能刷出生物，洞壁丝网随新区块生成。

## 生存合成与功能方块

从 **0.11.0-alpha.16** 起，收集相应材料后会解锁原版配方书条目。三根线可合成两捆绳索，绳索用于绳梯、帐篷和睡袋。首次探窟可用来路上的石化木或第二层巨木加工木板，制作铁级探窟镐。稀有遗物从探索和遗物鉴定取得。

| 设施 | 生存用法 |
| --- | --- |
| 营地炉与睡袋 | 一手拿生食、另一手拿煤、木炭或灯油，右击炉子烹制一份。恶魔鱼也可在熔炉、烟熏炉或营火上烹熟。右击睡袋会在有安全站位时设置重生点。 |
| 货箱、补给箱与笛架 | 两种箱子各有 9 格，储物随存档保存。用笛子右击笛架可展示，空手取回。 |
| 绳梯与运输站台 | 手持绳索或绳梯右击现有绳梯可下接一段。绞盘和升降井连接上下端站台，缆车连接水平站台。两端距离 2–64 格，中间铺设连续的缆索，终端旁要有站位。 |
| 深度计、罗盘、诅咒信标与日光钟 | 右击读取所在层深度、深渊方位、力场或可见日光时间。诅咒信标和日光钟可接比较器。 |
| 遗物鉴定台与发电机 | 一次用 9 块碎片鉴定出一件遗物。一块碎片向发电机补充 2,000 FE，发电机可向相邻设备供电。 |
| 除咒之笼与力场发生器 | 手持笼子或给放置的笼子投入遗物碎片可获得短时上升负荷防护。给接通红石的发生器使用结晶碎片，可短时抑制附近向上的动作。 |

## 远景与光影

无光影时，模组为各层设置大气颜色，第一层的大气和日照跟随奥斯的昼夜。洞口雾色随高度和洞壁距离渐变。启用 Oculus 或 Iris 后，光影包接管天空绘制和切层画面。夜视、速度等状态效果跨层后继续按原时间计时。

配套光影 **FantasyTruth Abyss - Bliss (Chocapic13' Shaders edit)** 基于 Xonk 的 Bliss 2.1.0。它在第一层洞体内绘制分离的云带和受岩壁遮挡的斜射光柱，使用 Distant Horizons 的深度数据与远处岩棚合成。雾幕亮度随日照变化，日光光柱在夜间熄灭。其他区域沿用 Bliss 的光影。默认阴影贴图为 1024，阴影视距为 192 格，体积效果以半分辨率计算。可用本地 Bliss ZIP 和 `python tools/build-abyss-shaderpack.py <Bliss.zip>` 生成配套包，输出到 `build/distributions`。

实测组合为 Minecraft 1.20.1、NeoForge 47.1.106、Distant Horizons 2.4.5-b、Embeddium 0.3.31、Oculus 1.8.0 和 Bliss 2.1.0。在启动器里把实例的 Java 最大堆设为 **8 GB**（`-Xmx8G`）。将客户端模组放进实例的 `mods`，将 Bliss ZIP 放进 `shaderpacks` 并在 Oculus 里启用。[Distant Horizons 2.4.5-b](https://modrinth.com/mod/distanthorizons/version/2.4.5-b-1.20.1) · [Embeddium 0.3.31](https://modrinth.com/mod/embeddium/version/0.3.31%2Bmc1.20.1) · [Oculus 1.8.0](https://modrinth.com/mod/oculus/version/1.20.1-1.8.0) · [Bliss 2.1.0](https://modrinth.com/shader/bliss-shader/version/2.1.0)

用 [DistantHorizons.toml](examples/orth-lod/DistantHorizons.toml) 配置 **384 区块（6,144 格）**和 **Surface** 后台生成，后台线程设为 4、运行占比设为 70%。FantasyTruth 0.11.0-alpha.4 针对 DH 2.4.5-b，在第一层保留背阴的洞壁与岩棚，将额外的垂直细节集中在洞体周围。配套光影按最近的方块或远景深度合成云雾，以免远处的雾覆盖近处岩壁边缘。原版视距可用 8–12 区块。

第一次进岛时，远景从玩家附近向外逐步生成。为了先补齐奥斯，可在 DH 高级设置中临时把世界生成中心设为区块 X=0、Z=0，生成半径设为 **112 区块**。近海完整后把生成半径调回 **0**，继续生成更远的世界。开启作弊后，可用 `/tp @s 8 999 1980 180 24` 从南港外海看全岛，或用 `/tp @s 65 856 251 180 33` 从洞口上方看内坡城区。如果 Bliss 的云雾遮住海岸，可以关闭体积云和体积雾。

奥斯区块按材质填入海水和岩层，用已知地表和海床高度写入高度图。Surface 阶段生成岛形、林地、地标和街屋轮廓。完整区块再生成室内、门窗、台阶和装饰。扩展高度保留 `−512 ≤ Y < 1024`。在 8 GB 单人实例中，从北方外海实机验证了连续全岛画面，并逐列检查了岛与近海范围的 2,214 个 LOD 区域。

## 旧版 Atlas 世界

面向 Minecraft 1.20.1 和 NeoForge 47.1.106 的实验性主世界类型。JAR 放进 `mods` 后，新建存档并选择「FantasyTruth：无限主世界（实验）」。原来的「FantasyTruth：大高差地形」预设仍可用于已有存档。Atlas 生成器只替换主世界。

0.4 版可在创建世界的「自定义」中打开 **Atlas 工作台**。它提供筛选表格、整份与分段 JSON、种子地图预览及整套应用。完整字段、默认值和数据包说明见 [CONFIG.md](CONFIG.md)。

0.5 版的新世界默认增加陆地占比，将高山集中到少数山脉，并把地表山峰平滑限制在海平面以上 420 格。出生点在加载区块前优先搜索低坡、成片的干燥陆地。Atlas 启动同步等待的出生区改为 7×7 区块，常驻刻范围随之缩小。玩家周边按正常视距加载。旧存档保留原有地形配置与出生点，同时使用优化后的区块生成代码和启动流程。

## 全局高度

- F3 的 `XYZ`、`Block` 和 `Chunk` 行在 Atlas 中显示全局高度或区段编号。`/strata altitude` 读取整数全局 Y。
- 管理员可用 `/tp <x> <y> <z>` 按全局 Y 传送，`~` 相对坐标也会跨页。极大整数高度可用 `/strata go <x> <全局Y> <z>` 精确输入。很深的落点可能位于岩石中。
- `/strata surface` 从高空或地下返回附近可站立的陆地，需要传送权限。向上和向下飞越边界会自动切页。远高于地表时，所在区块可能只含空气。
- 高度用有符号 64 位整数。每页拥有 1792 层，两端保留视图重叠。页面第一次被访问时才创建，存档落在 `dimensions/stratacubes/atlas_page/` 下。岩层、洞穴和矿脉以全局坐标生成。重叠带的方块状态按 16³ 单元保存并向相邻页同步。投影会通知归属页中的邻居并为流体补排更新。
- 在重叠带跨页挖掘、放置或使用方块时，客户端先切到该方块的归属页，切换完成后再操作一次。箱子的战利品和库存由归属页保存，另一页显示空壳。掉落物与经验球跨页转移并保留原实体数据。
- 这是页式实现。原版客户端通过维度切换刷新视图。交界附近的两页会保持区块更新，原版漏斗会查找归属页的库存。复杂红石、长漏斗链、其他实体、多人并发与整合包兼容性仍待验证或接入。

创建世界时，在数据包界面载入 `examples/atlas-profile`。编辑该数据包里的 `data/stratacubes/worldgen/world_preset/atlas.json`，然后创建新存档。选中的地形配置会和生成器一起保存。`biome_source.regions` 可把各气候区域指向数据包里的其他群系，地表岩土和装饰使用区域本身的生态规则。

| 字段 | 默认 | 可用范围 | 作用 |
| --- | ---: | ---: | --- |
| `sea_level` | 62 | −40000–40000 | 全局海平面与陆地基准 |
| `horizontal_scale` | 1 | 0.25–16 | 地貌的水平尺度 |
| `relief` | 1 | 0–20 | 大地形起伏倍率 |
| `foothill_detail` | 1 | 0–8 | 17–92 格尺度的山麓细节 |
| `rock_detail` | 1 | 0–8 | 岩坎、露头和层纹起伏 |

| `ravine_width` | 0.25 | 0.025–0.9 | 冲沟宽度系数 |
| `caves` | 1 | 0–2 | 三维洞穴幅度，0 关闭 |
| `temperature_offset` | 0 | −2–2 | 气候温度偏移 |
| `moisture_offset` | 0 | −2–2 | 气候湿度偏移 |
| `tree_density` | 0.85 | 0–1 | 群系树木密度倍率 |
| `settlement_spacing` | 144 | 64–4096 | 聚落候选网格间距 |

### 矿脉、地标与物品

数据包的 `data/stratacubes/atlas/content.json` 对新建和已有 Atlas 世界生效。已有世界把数据包放进存档的 `datapacks`，启用后重新进档。已生成的区块会保留原样。内容配置在世界加载时读取，修改后重新进档即可作用到后续生成的区块。

| 配置 | 可调整项 |
| --- | --- |
| `deposits` | 方块 ID、负 Y 变体、全局高度区间、每个 16³ 候选格的尝试次数、概率、矿脉半径、最少覆土深度和可替换岩石列表。任意普通方块都能作为矿脉或岩袋生成。 |
| `landmarks` | 规则 ID、结构类型、间距、概率、允许坡度、墙地板材料和战利品表。`kind` 可选 `homestead`、`watchtower`、`ruin` 或 `mine`。 |
| `fixed_sites` | 引用一条地标规则并指定 `x`、`z`，可选全局 `y`。省略 `y` 会贴地。可将地标规则的 `chance` 设为 0，仅生成手工指定的地点。 |
| `loot_tables/chests/` | 原版战利品 JSON。可调整物品 ID、权重、数量和抽取次数，也可把 `loot_table` 指向自定义表。开过的箱子保留已生成的物品。 |

默认生成煤、铁、铜、金、青金石、红石、钻石、绿宝石和砂砾团。用 `/strata locate any` 查找附近的生成坐标，或将 `any` 换成规则 ID，如 `mine`。已有存档需要去未生成区块核对预测地点。

例如，在 `fixed_sites` 加入以下条目，就会在该全局高度放置瞭望塔。`y` 是地板所在高度。

```json
{"landmark":"watchtower","x":128,"y":1000000000000,"z":-64}
```

矿物挖掘掉落继续读取对应方块的原版战利品表。要修改矿物挖掘产出，可在数据包覆盖 `data/minecraft/loot_tables/blocks/<矿石ID>.json`。 [Forge 1.20.1 战利品表文档](https://docs.minecraftforge.net/en/1.20.1/resources/server/loottables/)

## 算法与研究

- 大尺度地貌把抬升区、山脊与海盆分离。坡向决定冲沟噪声的拉伸方向，局部基岩纹理与中小尺度山麓叠加。0.4 加入基于坡降和有限步降雨累积的连贯切蚀。洼地溢流和完整水流模拟仍待实现。 [构造抬升与河流侵蚀](https://perso.liris.cnrs.fr/apeytavi/website/publication/hal-01262376/) · [受控程序化侵蚀纹理](https://doi.org/10.1111/cgf.14992)
- 洞室与细管由绝对坐标的三维隐式场生成，跨区块使用同一组边界样点。当前岩层用共享周期场构造，地貌细节可独立于山体高度调整。 [隐式三维地貌细化](https://perso.liris.cnrs.fr/apeytavi/website/publication/hal-02273097/)
- 海拔降温、风向雨影、湿度和水岸位置共同划分 13 个群系。树木按区域选择针叶、阔叶或雨林树的分枝规则，树冠由枝端生长。聚落先筛掉沟谷和过陡坡面，再按地基、柱梁、立面及屋面规则生成住宅与附屋。 [植物程序化建模](https://algorithmicbotany.org/papers/) · [建筑形状文法](https://doi.org/10.1145/1141911.1141931)

## 已验证

- 0.5 版的固定种子对照使用同一地形配置、出生坐标和 1.20.1 客户端。启动准备从 8.31 秒降到 2.10 秒，远处 9 个区块从 628 毫秒降到 538 毫秒。两版 9 个区块的全高度方块校验值一致。新版默认地形与出生搜索另做了 8 个种子的样本对照和真实客户端进服验证。
- 0.4 版在隔离客户端验证了工作台表格与 JSON 互通、矿脉批量倍率、导出数据包、连续两次应用及重启读档。最终存档只保留最后一份工作台数据包，实际生成的地表高度与预览模型一致，指定结构和自定义箱子战利品均生效。
- 0.3 版的隔离客户端测试通过了水流越过接缝、另一页红石灯亮灭、漏斗跨页转移物品、箱子单份库存、掉落物切页与重启恢复。旧版 Atlas 存档也通过了数据包覆盖测试，在 Y = +10¹² 生成手工指定的地标并按自定义战利品表生成物品。
- 用 NeoForge 47.1.106 的隔离单人客户端创建 Atlas。测试跨越主世界上层交界，在相邻页读到镜像方块，跳转到全局 Y = −10¹² 和 +10¹²，并在重启客户端后恢复 +10¹² 页的玩家位置与测试方块。
- 种子 72019 的核心采样覆盖 63,001 个位置，地表 Y 为 −69 至 925，观测到 11 种地表群系。以 8 格为步长的高度二阶差分绝对值均值从旧版的 0.22 增至 1.80。另在实际存档中确认生成了岩层、树枝、树冠与住宅屋顶。
